# ADR-0019: 产品与项目目录进入主侧栏

- **状态**: accepted
- **日期**: 2026-09-09
- **来源**: 用户确认 Product → Project → Application，并确认主侧栏树形导航方案。
- **更新**: ADR-0014 的分类名称与层级；ADR-0015 的同地域分享范围改称同产品范围。

> 2026-09-14 更新：新上传制品的项目下载前缀遵循 [ADR-0022](0022-project-download-prefix.md)，历史制品文件名仍保持不变。

## 决策

产品是原地域分类的新名称。开封、三沙、十堰等现有条目的名称与 ID 保留，不将它们移成项目。每个项目属于一个产品，每个应用属于一个项目。项目用于归类应用，不引入任务、进度或项目级权限。

每个产品有一个默认项目。迁移将现有应用归入所属产品的默认项目，保持应用、制品、发布和分享链接的身份与历史文件名不变。管理员可以新增、重命名、排序、停用项目；非默认项目为空时可删除。默认项目允许重命名，但不能停用或删除，确保旧客户端有稳定的归属目的地。删除没有应用的产品时，其空项目一并删除。

产品和项目基础资料供登录用户读取。只有管理员可维护目录；应用的可见性和操作权限仍由 application_members 决定。计数只来自当前用户可访问的应用，目录归属不授予权限。停用产品或项目阻止新的绑定，已有应用仍可访问和编辑其他元数据。

## 界面与交互

- 主侧栏上方保留工作台、应用、产品管理、设置，下方是独立滚动的应用目录，主内容区不再放第二条竖向目录。
- 点击产品名称显示该产品的全部应用并展开子目录；点击箭头只展开/收起，不切换筛选。通常只展开一个产品；查找目录时展开匹配分支。
- 点击项目筛选该项目；切换产品清除旧项目选择。内容区显示当前归属，空项目提供新建应用入口。新建应用继承当前产品与项目。
- 收展使用 220ms 高度与透明度过渡，折叠内容不可聚焦；遵循系统减少动态效果偏好。
- 窄屏使用产品、项目两个紧凑选择器；侧栏抽屉也可选择目录，选择后关闭。
- URL 使用 product / project。旧 region 查询链接仍可访问；跨设备目录偏好增加项目 ID。

### 产品管理页（2026-09-10）

用户确认产品管理采用铺满顶栏下方的左右分栏：左侧选择产品，右侧原位维护项目。移除页面内的大标题和外层卡片；两栏分别滚动，窄屏上下排列。应用列表的主侧栏目录不受影响。

新增和重命名项目使用原位表单，Enter 保存、Esc 取消，产品间切换保留各自未提交的草稿。选择同步到 URL，支持返回与直达。停用、删除收进有文字说明的菜单；默认项目与非空项目的限制继续由 API 执行。旧设置页的“管理项目”入口进入同一管理页面。

项目排序支持拖动、键盘及菜单上下移动。一次请求在事务内保存完整顺序，校验所属产品、完整项目集合与客户端读取的原顺序；遇到其他人的新增、删除或排序变更时拒绝覆盖并刷新。请求失败时恢复服务端顺序，无需新增数据库迁移。

### 详情页延续应用目录（2026-09-11）

应用列表与详情页使用同一个侧栏目录，扩展为产品 → 项目 → 应用。产品/项目名称返回对应筛选列表，展开箭头仅切换分支；应用名称进入详情。直达详情自动展开当前路径并高亮应用，其他分支不预加载应用。目录展开、搜索、折叠与滚动位置在当前会话内按用户隔离保存。切换详情的加载/错误状态不会卸载目录。

点击卡片后，若当前应用不在目录可见区域，等待分支展开后仅对目录容器平滑滚动，将应用置于视窗中部附近；已经可见则保持原位。新的选择取消旧定位，减少动态效果模式使用即时定位。

应用叶节点复用有权限过滤的分页接口，每次最多 30 条，按项目展开时读取并缓存；可以加载更多。缓存过期或写操作使缓存失效后，在已有条目上后台更新。直接打开后续页的应用时，先展示当前已获授权的应用，后续加载时按 ID 去重。搜索同时提供产品/项目名称匹配及带归属路径的应用结果，不遍历全部制品或一次加载完整应用目录。

详情页签由 `tab` 查询参数控制，切换应用保留当前有效页签，不携带旧应用的编辑参数。目标应用无管理权限时，设置/分享页签回退概览。手机沿用侧栏抽屉，点击应用后关闭抽屉。前端测试覆盖按需加载、缓存复用、搜索、重试、后续页去重及页签权限；真实浏览器验证延迟加载详情期间树保持挂载、条目不清空、同项目切换不重新请求目录。

## 兼容与数据库约束

保留数据库 regions / region_id 和既有 Region API 字段、/settings/regions 接口。这些是兼容名称，领域含义统一为产品。前端 Product 为规范类型，Region 为兼容别名。旧 /regions 页面跳转到 /products。

新增 projects 表和 applications.project_id。复合外键 (region_id, project_id) 引用 (projects.product_id, projects.id)，防止应用跨产品关联项目。项目名称在同产品内唯一，默认项目在同产品内唯一。产品插入触发器创建默认项目；应用插入或旧客户端仅变更产品时，触发器补齐默认项目。

项目不进入制品分发文件名，已发布文件名不可变。新文件名继续使用产品代码（旧 region code）。分享清单维持同产品范围，可覆盖其多个项目，不修改现有分享令牌。

### 分享入口跟随目录节点（2026-09-11）

创建分享清单时，以当前选中的目录节点确定候选范围：产品节点可选择该产品各项目的应用，项目节点只能选择该项目的应用；操作文案、弹窗标题和默认清单名称同步使用对应节点。空项目或无效项目不得回退到父产品的候选列表。这细化了创建入口的选择范围，分享清单本身仍遵守 ADR-0015 的同产品约束，现有链接不变。

分享弹窗按需调用带产品、项目范围的分页接口，服务端先过滤维护权限、未归档且有制品的应用，再计数和分页。每页 20 项，跨页保留选择但每张清单仍最多 20 项；不截断候选总数，也不请求全量应用目录。弹窗状态由独立组件持有，避免打开或操作弹窗时重新渲染应用目录树。

## 迁移与验证

- 0022_product_projects：创建项目、回填应用，再施加非空和复合外键；不改写既有迁移。
- 0023_project_preferences：增加可空的项目浏览偏好，删除项目时清空相应偏好。
- PGlite 集成测试执行全部历史迁移，并在 0022 前插入旧格式数据；验证回填、旧客户端、跨产品外键、管理员限制、应用权限、停用与删除规则、偏好恢复。
- 前端测试覆盖独立展开、筛选选择、历史恢复和手机产品切换时的项目重置。真实浏览器使用隔离的本地数据库验证创建与管理流程。
- 上线仍须按 ADR-0008 备份生产库，并在 PostgreSQL 16 预发布库执行迁移演练。PGlite 测试不替代该演练。

## 取舍

暂时保留旧数据库和接口名称，可让已有自动上传、MCP、分享和外部调用继续工作。一次性重命名所有外部契约会增加无关迁移风险。默认项目是无损归属方式；用户可随后在应用设置中调整项目，不根据应用名称猜测业务分组。
