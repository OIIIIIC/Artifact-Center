# ADR-0027: 应用选择 Jenkins 连接

- **状态**: accepted
- **日期**: 2026-11-03

多个团队或环境可能分别使用不同的 Jenkins 实例。将 ADR-0024 中的单一平台连接扩展为管理员维护的命名连接；Application 的 Build Configuration 保存 `connectionId`，Build Run 保存发起时的连接 ID、地址与账号快照。

迁移 `0034_multi_jenkins_connections` 移除连接单例约束，为既有配置和构建回填 `default`。既有地址、账号、加密 Token、任务及产物不变。连接 ID 保持不可变；停用代替删除，避免历史记录意外引用其他服务器。禁用草稿可先保存未配置的连接，启用时必须验证所选连接与任务。

工作器、日志、取消、下载及导入均按 Build Run 的连接 ID 读取凭据，同时核对地址与账号快照。修改应用绑定不会让旧构建读取新服务器；停用一个连接不影响其他连接。相同连接内更新 Token 可继续读取历史。修改地址或账号仍必须输入新 Token。

设置页管理多个连接，应用构建配置选择服务器。仅管理员可管理连接和应用绑定；维护者只读取连接的 ID、名称和启用状态，不获得其他连接的账号或凭据。保留旧 `/settings/jenkins` 读写接口为 `default` 连接的兼容入口；新增 `/settings/jenkins/connections/:connectionId` 保存连接及其 `/test` 检测入口。读取设置返回完整脱敏连接列表。

任务校验同时接受 Pipeline 和 FreeStyleProject，沿用普通参数白名单、选项验证和构建权限检查。文件夹和多分支父任务仍不可直接绑定。自由风格任务需使用“归档成品”后置操作提供候选构建产物；平台不自动修改任务或赋予部署权限。
