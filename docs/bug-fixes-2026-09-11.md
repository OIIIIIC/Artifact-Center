# 2026-09-11 BUG 修复与验证

对应用户提供的 `BUG记录.md` 中 BUG-001、BUG-002、BUG-003。

## 修复结果

| 问题                         | 原因                                               | 修复                                                                        |
| ---------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------- |
| BUG-001 管理员移交下拉被遮挡 | Select Portal 层级 50，低于弹窗遮罩 100 和内容 101 | 共用 Select 浮层提升到 110，适用于其他弹窗中的 Select                       |
| BUG-002 制品菜单不关闭       | 自建 Portal 菜单缺少外部点击和键盘关闭处理         | 监听外部 pointerdown、Escape；Escape 后恢复原触发按钮焦点；保留内部删除确认 |
| BUG-003 切换账号显示旧数据   | 查询缓存跨账号存活，且查询观察器可能保留上一次结果 | 账号改变时重建查询上下文与观察器，同步清理旧缓存并取消旧查询                |

账号资料和令牌在同一账号下更新时不会重建查询上下文，避免清空未保存输入。另修复相关会话边界：旧请求晚到的 401 响应不能登出新账号，JSON、Blob 和上传请求均按发起时的令牌校验；当前账号的 401 仍正常退出。
